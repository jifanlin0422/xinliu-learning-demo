# 心流物语学习工作台 · 公开演示

可操作的个人学习工作台原型：课程、大纲、掌握热力图、学习、物语诊断、心流练习与闪卡复习。

直接打开页面即可体验，不需要登录。数学示例课程中的“正数和负数”可体验完整物语与心流流程；练习每轮最多10题，支持保存与续练，徽章仅显示图标。

热力图默认展示演示颜色与图标；完成测评不会自动关闭演示。右侧“演示 / 我的”明确切换数据来源，刷新后保留选择。此次更新将旧版未区分自动／手动的显示状态恢复为演示一次，不改动已有课程和作答记录。

这是前端交互演示，AI问答和自动出题未接入线上服务。上传材料和进度保存在访客自己的浏览器内；此仓库仅含公开页面构建文件，不含服务密钥、原始教材、学习记录或收货信息。

`index.html` 是主页面，`runner-demo.html` 是独立动画演示，PDF.js 许可保留在 `PDFJS-LICENSE.txt`。
